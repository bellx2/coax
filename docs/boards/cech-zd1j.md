# Sony CECH-ZD1 J（バックエンド`cech-zd1j`）

| | |
| --- | --- |
| バックエンド | `cech-zd1j`（別名`mb86h47`）|
| 対応OS | Linux / Windows / macOS（直接USB）|
| 伝送方式 | ISDB-T |
| ファームウェア | 不要 |

富士通のMB86H47Aと、DiBcomのDiB8096（DiB8000復調器とDiB0090チューナーを1パッケージにしたもの）が載っています。

## 対応製品

| 製品 | VID:PID | チューナー本数 | 伝送方式 |
| --- | --- | --- | --- |
| Sony CECH-ZD1 J | `054c:04b2` | 1 | ISDB-T |

## LED

前面のLEDは、DiB8096のGPIO 1につながっています。
GPIOを出力にしてHighにすると赤、Lowにするか入力のままにすると緑です。
`coaxd`は、チューナーを使っている間はLEDを赤にし、使い終わると緑に戻します。

## 定義ファイル

共通の書式は[channel-files.md](../reference/channel-files.md)にあります。
`FREQUENCY`だけが必要で、6MHz幅のISDB-T（13セグメント）として選局します。
伝送パラメーター（モード、ガードインターバル、各階層の変調方式）はDiB8000が自動で判別します。
自動の判別に失敗したときは、地上デジタル放送の標準的なパラメーター（ARIB TR-B14）で選局します。
それでもロックしなければ、DiB8000が読んだTMCCの値で選局し直します。


## 選局の速さ

選局を短くするため、次の2点はLinuxのドライバと違う動きをします。

- ストリームは、どれかの階層のMPEGロックが取れた時点で流し始めます。Linuxは、インターリーブがいちばん長い階層（地上波ではワンセグのA階層）のロックを待ちます。実機ではA階層がフルセグのB階層より約300ms遅れてロックしたので、その間を待たずに済みます。流し始めの数百msは、A階層のパケットが欠けることがあります
- DiB0090の温度は、前に測ってから1分以内なら測り直しません。Linuxは選局のたびに測ります（10ms以上の待ちが4回）。温度は広帯域検出器の目標値の補正にだけ使います

温まった状態（`coaxd`が動いていてボードを開いたまま）で、選局から最初のバイトまでは1.04〜1.44秒から0.78〜0.92秒になりました（地上波8局で測定）。
